## 规则说明

水杯类别会排除文胸、内衣、罩杯、鞋、背包等明确冲突内容；包和鞋类别也会排除强冲突词。
商品配件（例如杯垫、杯盖、鞋架、鞋盒）在没有目标商品主体词时会进入排除清单。
规则只处理高置信度冲突，不根据标题缺少某个关键词就直接删除图片。
