## 一、实验四对象与本组口径

任务书用 CIFAR-10、技术博客文本、量化 ResNet / 蒸馏 BERT 举例，那是通用模板。本组沿用实验 1–3 的真实对象，报告按本组口径写，不照抄模板里的数据集名：

| 任务书举例 | 本组实际对应 |
|---|---|
| CIFAR-10 图像数据 | 10,165 条电商商品图，9 个大类（鞋/水杯/包/男装/运动服/女装/手机壳/厨房用品/家居用品） |
| 技术博客文本 | 商品中文文案与用户中文查询词（MUGE/苏宁/Amazon 中文化后的 `item_name`/`description`） |
| 图文对数据 | 商品图文对，即双塔检索的一条 query–image 样本 |
| 量化 ResNet / 蒸馏 BERT | 实验三主线产物：Chinese-CLIP 双塔微调权重（`epoch3.pt`）+ 图像塔 TensorRT/ONNX、文本塔 ONNX（延迟 −57.7%、吞吐 +136.6%、精度 −0.43pp） |

因此三个页面按本组数据落地：**图像分类页**（上传商品图 → 图像塔编码 → 类别/相似商品）、**文本分类页**（输入中文查询 → 文本塔编码 → 相关商品）、**多模态匹配页**（图 + 文同时输入 → 双塔比对类别一致性 → 匹配结果）。

后端集成的是实验三优化模型，优先用 **ONNX Runtime** 加载双塔 ONNX（CPU 即可跑）；TensorRT 需 GPU 机器，仅作可选加速后端，报告注明运行环境。

> 待定：模型怎么在本机调用（ONNX 产物路径、权重来源）尚未确定，由 wlz（王陆洲）与 何朝杨 对接后写进架构文档。本轮不声称模型已能在本机跑通。

## 六、报告口径红线

- 任务书的 CIFAR-10 / 技术博客 / ResNet / BERT 是模板举例，本组对象是电商图文与 Chinese-CLIP 双塔；报告按本组口径写，不照抄示例数据集。
- 后端叫"集成实验三优化模型"，指的是加载实验三导出的 ONNX 双塔产物，不是重新训练模型。
- 性能数字要标清是哪个后端（CPU ORT 还是 GPU TRT）在什么机器上测的，CPU/GPU 数字不混算。
- 没做的部分（如 Safari 真机、Docker 生产部署）如实注明，不声称已测。
- 模型能否在本机跑通尚未确定，未跑通前不在报告里声称有实测推理结果。
