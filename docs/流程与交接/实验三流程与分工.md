## 一、方法选择与范围

### 1.1 量化探索已冻结

六种配置的动态量化探索见 [原始量化记录](../optimize/runs/2026-10-23_exp3-quant/02-精度评测.md) 和 [方案与口径](../optimize/00-方案与口径.md)。本轮不重新执行 INT8、4-bit、静态量化、量化后微调或剪枝。

主任务改为 3.1.4：双塔导出 ONNX，图像塔比较 PyTorch、ORT-CPU、ORT-CUDA、TensorRT；精度用同一 934 条测试文本和 934 张候选图片。旧量化对比只作为历史探索，不能代替主线验收。

### 1.2 本轮可以证明什么

| 测量 | 范围 | 可以得出的结论 |
|---|---|---|
| 速度 | 图像塔 forward，batch 1 / 32 | 图像编码部分的稳态延迟和吞吐收益 |
| 精度一致性 | 双塔文搜图，934 查询、934 候选 | ONNX/后端配置相对同源 FP32 基线的整体 R@K 变化 |
| 历史端到端参考 | 132 条 AI 查询的旧索引 Top-10 排序复算 | 历史查询的 Precision/Recall/nDCG/MRR，可用于说明既有系统基线 |
| 本轮未测 | TRT 的 132 查询重检索、文本塔独立测速、整系统延迟、TRT 分类别损失 | 不做对应的性能提升或分类别损失声明 |

延迟降低 ≥40%、吞吐提升 ≥50% 是 3.1.4 的速度目标；R@1 绝对差 ≤1pp 是精度条件。3.2.1 本轮明示口径为加速比 ≥1.2、R@1 绝对差 ≤0.5pp。pp 指百分点，不是相对百分比。

## 二、最新正式结果

正式归档：[exp3_inference_acceleration_20261025](../../evaluation/retrieval/results/runs/exp3_inference_acceleration_20261025/测试结果说明.md)。所有数字由脚本读取已核验 JSON 重新计算。

| 后端 | batch | PyTorch / 引擎延迟 ms | 加速比 | 延迟降低 | 吞吐提升 |
|---|---:|---:|---:|---:|---:|
| ORT-CPU（8/8线程） | 1 | 90.56 / 85.24 | 1.062× | 5.87% | 6.36% |
| ORT-CPU（8/8线程） | 32 | 2532.61 / 2554.38 | 0.991× | −0.86% | −0.79% |
| ORT-CUDA | 1 | 4.98 / 4.54 | 1.097× | 8.84% | 9.81% |
| ORT-CUDA | 32 | 50.90 / 54.55 | 0.933× | −7.17% | −6.70% |
| TensorRT | 1 | 4.59 / 1.94 | 2.366× | 57.73% | 136.58% |
| TensorRT | 32 | 50.43 / 23.84 | 2.115× | 52.73% | 111.52% |

PyTorch FP32 的 R@1 为 58.5653%；ORT-CPU FP32 为 58.5653%（0pp）；TRT FP16 为 58.1370%（−0.4283pp）。主线速度与精度条件通过。速度是图像塔范围，不能扩写为整套用户查询加速 2.37 倍。

早期文档的 ORT-CUDA 1.05× / 0.95× 和文本塔约410MB不作为本轮数值来源；归档 JSON 对应 1.097× / 0.933× 和文本塔 FP32 ONNX 389.58MiB。

## 五、其他开发者复现

进入仓库根目录，激活已经安装依赖的 Python 环境；已有 pytorch 环境可以继续用。Conda 环境必须正常激活，不要仅双击其 python.exe，以免底层数值库的 DLL 路径缺失。

    python -m pip install -r evaluation/retrieval/requirements-report.txt
    python evaluation/retrieval/code/evaluate_acceleration.py --run-id exp3_report_my_run

也可以：

    .\evaluation\retrieval\scripts\run_exp3_evaluation.ps1 -RunId exp3_report_my_run

默认不覆盖现有 run。显式使用 --overwrite / -Overwrite 才会覆盖脚本同名产物；自定义 run-id 只能是一个目录名。路径按仓库根目录解析，输出统一到 evaluation/retrieval/results/runs/。

只重绘已有一轮：

    python evaluation/retrieval/code/render_acceleration_charts.py --run-dir evaluation/retrieval/results/runs/exp3_inference_acceleration_20261025

使用该轮冻结输入生成新的结果：

    python evaluation/retrieval/code/evaluate_acceleration.py --config evaluation/retrieval/results/runs/exp3_inference_acceleration_20261025/inputs/evaluation_config.json --run-id exp3_report_from_snapshot

逻辑测试：

    python -m unittest discover -s evaluation/retrieval/tests -p test_acceleration.py -v

Linux 绘图需要安装 Noto Sans CJK SC 等中文字体；无可用中文字体时脚本会报错，避免输出方框字。
