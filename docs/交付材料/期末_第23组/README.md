| 接口延迟（30 次暖机，均值/P95） | 文本 / 图片 / Agent 文本 / Agent 图片 | 46.4/64.4、115.8/127.4、48.2/140.0、128.1/130.1 ms |

## 四、口径红线（别混用）

- 工具调用必须双口径：**纯模型 90%，加参数规范化 100%**，不能只报 100%。
- v4 的 **82.5%** 是 40 道协议考题的全项通过率（33/40），不是线上搜库召回率。
- 实验二是 **Chinese-CLIP 全参微调**（RTX 5060 Ti），不是 LoRA；QLoRA 只用于实验五的 Qwen3-4B。
- 实验三加速是 **GPU 训练机同硬件配对测速**，源记录未含具体显卡型号，不补写；RTX 3080Ti 是实验五 v2 评测用机。
- 速度只覆盖图像塔 forward，不是完整检索请求的端到端加速。
- 数据库没有价格与销量字段，Agent 不承诺这两类查询。
