## 编译

在仓库根目录执行：

```powershell
& 'docs\typst\typst.exe' compile --root . `
  'docs\typ\实验五.typ' `
  'docs\build\实验五-第23组-YYYYMMDD.pdf'
```

报告已加入文献引用、图表交叉引用、实验阶段复用关系、问题解决方案和小模型/生成式模型微调对比，并写入两张 v2 评测截图。

报告中的数字以仓库的训练凭证、`data/agent/eval_*.json`、`data/agent/eval_v*.json` 和 `evaluation/retrieval/results/runs/` 为依据。报告没有把未完成的前端 npm 回归、浏览器兼容截图和录屏写成已完成结果，最终提交前需补齐这些材料并更新第八章和交付目录。
