# 对照组实验：未清洗数据直训（2026-10-20）

> 目的：补齐实验二「五.2 对比实验」缺的那一列——用**未做视觉清洗与属性增强**的原始表训练一个模型，
> 与主实验（清洗数据微调）在同一 test 集上对比，从而把总提升拆分为"微调本身"与"数据清洗净贡献"。
>
> 主实验记录见 [`03-微调结果.md`](03-微调结果.md)。

## 1. 结论

| 指标 | 预训练基线 | **未清洗直训** | 清洗数据微调 | 直训增益 | 清洗增益 |
|---|---:|---:|---:|---:|---:|
| R@1 | 37.37 | **50.96** | 58.67 | +13.59 | **+7.71** |
| R@5 | 70.77 | 84.48 | 89.08 | +13.71 | +4.60 |
| R@10 | 82.44 | 93.04 | 96.90 | +10.60 | +3.86 |
| mean_recall | 63.53 | 76.16 | 81.55 | +12.63 | +5.39 |

拆分（以 R@1 计）：

```
37.37 → 50.96   微调本身     +13.59（占总提升约 64%）
50.96 → 58.67   数据清洗     +7.71（占总提升约 36%）
```

关键观察：清洗后样本由 **10,165 减到 9,393**（少 772 条），**样本变少而效果更好**，
说明该场景下"质量优于数量"。

## 2. 数据

| | 主实验（清洗） | 本对照组（未清洗） |
|---|---|---|
| 数据源 | `data/processed_data_cleaning/` | **`data/processed_data/`** |
| 总条数 | 9,393 | **10,165** |
| 训练 / 验证 / 测试 | 7,520 / 939 / 934 | **8,146 / 1,019 / 1,000** |
| 差异 | 视觉模型补 `type`/`color`/`material`、重写 `description`、排除 765 条非目标商品 | 字段为来源原文，含脏样本与空属性 |

数据集目录：`data/processed_data_retrieval/datasets/ShopVision_uncleaned/`（tsv/jsonl + lmdb）。

> 注意：目录名里的 `uncleaned` 指"未做视觉清洗"，来源是 `data/processed_data/`，
> **不是** `data/raw_data/`（那份是未翻译、未分类的采集原样，差异太多，不适合做单变量对照）。

切分同样按 `item_id` 的 MD5 哈希 8:1:1，因此同一商品在两个数据集中落在同一划分，
清洗数据的 934 条 test 商品在本数据集中也是 test，**不存在训练集见过考题的情况**。

```bash
  bash scripts/finetune/run_train_single_gpu.sh
```

## 4. 训练过程

耗时约 13 分钟（12:33:19 → 12:40:22），共 8 次验证：

| 时间点 | Valid Loss | Image2Text Acc | Text2Image Acc |
|---|---:|---:|---:|
| epoch1 @ 150 步 | 0.4113 | 84.47 | 85.35 |
| epoch1 @ 255 步 | 0.3705 | 85.35 | 86.72 |
| epoch2 @ 300 步 | 0.3934 | 85.45 | 86.72 |
| epoch2 @ 450 步 | 0.3603 | 87.70 | 87.11 |
| epoch2 @ 510 步 | 0.3333 | 87.21 | 87.89 |
| epoch3 @ 600 步 | 0.3350 | 87.70 | 88.09 |
| epoch3 @ 750 步 | 0.3273 | 88.87 | 89.26 |
| **epoch3 @ 765 步** | **0.3273** | **88.87** | **89.26** |

对比主实验（清洗数据）最后一点：`Valid Loss 0.1403 / I2T 94.69 / T2I 94.48`。

⚠️ 两组的验证集**不是同一批**（1,019 条 vs 939 条），所以这两个数字只能看方向、不能直接写进报告；
最终结论一律以固定的 test 934 条为准。

## 7. 局限

1. **test 集第二次使用**。主实验已用过一次；本次用它做组间对照属于必要的横向比较，
   但此后不应再拿同一 test 反复调参，后续选型只依据 valid。
2. **两组验证集不同**，valid 指标不可直接横比（见第 4 节）。
3. **未清洗数据里含 765 条被判"非目标商品"的样本**（如水杯类误收的袜子），它们进入对照组训练集
   是刻意的——这正是"脏数据"的体现，不是数据准备错误。
4. 与主实验一样，本组也只跑了一次、3 轮，未做多 seed 重复，绝对数字不宜过度解读；
   但组间差距（+7.71）远大于随机波动量级。
