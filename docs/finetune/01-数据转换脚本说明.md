# 数据转换脚本说明

> 本文档属于微调流程的第 1 步,说明 `scripts/build_retrieval_dataset.py` 的作用和用法。
> 本文档是新增文档,不修改任何现有文档。

## 作用

把 `data/processed_data_cleaning/` 下 9 个类别的商品数据,转成 Chinese-CLIP 官方微调脚本认识的格式:

- `*_imgs.tsv`:图片 id + base64 编码的图片内容
- `*_texts.jsonl`:文本 id + 文本内容 + 对应的图片 id 列表

## 用法

```bash
# 默认参数(推荐)
python scripts/build_retrieval_dataset.py

# 自定义参数
python scripts/build_retrieval_dataset.py \
    --input-dir data/processed_data_cleaning \
    --output-dir data/processed_data_retrieval/datasets/ShopVision \
    --train-ratio 0.8 \
    --valid-ratio 0.1
```

## 关键设计

### 1. 文本格式和索引一致

文本用 `scripts/retrieval/text_builder.py` 里的 `build_product_text()` 生成,和建 FAISS 索引时用的是同一个函数。

**为什么重要**:微调是让模型适应"你的文本长什么样",如果微调的文本和索引的文本格式不一样,微调就白做了。

### 2. 按 item_id 哈希切分

用 `item_id` 的 MD5 哈希值取模做 8:1:1 切分:

- 同一商品永远落在同一划分(train/valid/test),不会泄漏
- 切分是确定性的,多次运行结果一致
- 不需要保存切分结果,重新跑一遍就能还原

### 3. 数字 id 全局递增

从 1 开始递增,不按类别分段。简单、不会冲突。

`id_mapping.csv` 记录 `numeric_id ↔ item_id` 的对应关系,用于把检索结果翻译回商品。

### 4. 跳过规则

以下情况会跳过该商品,并计入统计:

- `local_image_path` 为空或文件不存在
- 图片文件读不出来(损坏、格式不支持等)
- `build_product_text()` 生成的文本为空

## 输出

```
data/processed_data_retrieval/datasets/ShopVision/
├── train_imgs.tsv       # 训练集图片(80%)
├── train_texts.jsonl    # 训练集文本
├── valid_imgs.tsv       # 验证集图片(10%)
├── valid_texts.jsonl    # 验证集文本
├── test_imgs.tsv        # 测试集图片(10%)
├── test_texts.jsonl     # 测试集文本
└── id_mapping.csv       # numeric_id ↔ item_id 对照表
```

运行后会打印统计报告:总数、成功数、跳过数、按类别和按划分的分布。
