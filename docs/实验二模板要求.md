## 一、模板要求（硬性）

### 章节结构

1. 实验目的
2. 实验环境（软硬件环境）
3. 实验内容与步骤（需至少覆盖前三部分）：
   - 2.1 环境部署：深度学习框架安装、开发工具与环境
   - 2.2 模型选型：计算机视觉模型、自然语言处理模型、多模态/多任务模型
   - 2.3 训练优化方法：计算效率优化、梯度控制方法、训练过程控制
   - 2.4 模型适配策略：解决小样本/非标数据的泛化问题（选做）
   - 再按 1．需求分析 / 2．设计思路 / 3．代码实现 / 4. 测试优化 展开
4. 实验关键技术与难点
5. 实验结果与分析
6. 实验总结与展望
7. 参考文献

### 第五部分的四条硬性要求

1. **必须包含数据-模型关联表**：列出实验 1 的数据集特点（如样本量、增强方式）与实验 2 的模型选型/优化策略对应关系；
2. **对比实验需基于实验 1 的原始数据与增强数据**，验证"数据增强 → 模型性能提升"的因果关系；
3. 训练优化需要有明确的前后对比结果呈现和分析（含提升比例）；
4. 适配策略需要实验验证。

### 另一条评分点

- **问题分析需关联实验 1 的预处理环节**（问题要能追溯到采集/翻译/去重/质检/视觉清洗等环节）。

### 排版要求

正文小四宋体 + Times New Roman、行距 20 磅；图表中标题和文字均为五号。已按 `docs/typ/实验一.typ` 的排版规范实现。

# 2) 用官方脚本打包 LMDB（参数见 docs/finetune/02-微调训练.md 第三节）
