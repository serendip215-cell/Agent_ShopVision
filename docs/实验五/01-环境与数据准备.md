# 实验五 5.1 环境与数据准备

负责人是杜军博。阶段产物是 5.2 LoRA 微调的数据前置。

## 输入与输出

- 输入：data/processed_data_cleaning/*/products.csv
- 脚本：scripts/agent/build_agent_finetune_data.py
- 输出：data/agent/agent_finetune_data.json
- 清单：data/agent/agent_finetune_manifest.json

仓库版本控制文件没有包含实验一中间文件 text_data.json。本次使用已审核清洗商品表生成等价标准商品文本。模板复用了 scripts/retrieval/text_builder.py 的字段顺序。

## 环境

**本步骤（数据生成）不需要 GPU，也不需要 torch。** 只用 Python 标准库 + csv/json，
任意 Python 3.10+ 环境都能跑：

```bash
python scripts/agent/build_agent_finetune_data.py
```

`scripts/agent/requirements.txt` 里列的是**后续 5.2 训练/5.3 推理**才需要的依赖
（torch / transformers / peft 等），跑 5.1 不必装。

如果要做 5.2 训练或 5.3 推理，建议独立环境：

```bash
conda create -n shopvision-agent python=3.12 -y
conda activate shopvision-agent
pip install -r scripts/agent/finetune/requirements.txt
```

检查（训练/推理环境才需要）：

```bash
python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
```

**注意**：5.1 阶段只准备数据，不下载基座模型、不训练 LoRA、不接 LangChain。


## 数据分配

共 100 条，随机种子为 42，按类别轮询抽样。

| task | 数量 | 用途 |
|---|---:|---|
| attribute | 60 | 复用商品属性清洗逻辑 |
| intent | 25 | 将自然语言需求转换为检索意图 |
| tool_call | 15 | 生成白名单 text_search 工具参数 |

每条记录包含 id、task、item_id、category、instruction、input、output。商品事实来自清洗 CSV，工具调用输出为 JSON。

## 执行

在仓库根目录运行：

    python scripts/agent/build_agent_finetune_data.py

## 验收

    python -c "import json; p='data/agent/agent_finetune_data.json'; d=json.load(open(p,encoding='utf-8')); assert len(d)==100; assert len({x['id'] for x in d})==100; assert all({'instruction','input','output'} <= set(x) for x in d); print('5.1 数据格式通过')"

通过后，将两个 JSON 和本文件交给刘凡思雨开始 5.2。

## 补充：v2 扩充数据（2026-11-08）

上述 100 条是 **v1** 数据。5.3 实测发现它的 tool_call 样本有致命缺陷：
15/15 全是「帮我搜索XXX，**限制在X类**，返回N个结果」，**类目明写在句子里**，
模型只学会照抄，不会从商品名推断。

已重建 **v2** 数据（163 条，tool_call 从 15 扩到 78、且 query 里不含类目名）：

```bash
python scripts/agent/finetune/build_tool_call_expanded.py
# -> data/agent/agent_finetune_data_expanded.json
```

生成脚本会做自检：用 `category_map.infer_category` 反向推断，
必须能推回原类目才保留该样本。

详见 [`09-5.3优化实跑：扩充数据重训.md`](09-5.3优化实跑：扩充数据重训.md)。

**v1 数据保留**作为「训练数据模板有问题」的对照组，报告里可以对比。
