# 5.4 对话 Agent v4 多轮训练规范

> 读者：负责训练 LoRA 的同学 / 训练 AI。
> 目标：在 v3（单轮：会选工具、会聊天、会点评）基础上，**加入多轮上下文**——
> 省略继承、指代查详情、话题切换、纠错、澄清追问。
> 产物：`dist/lora_adapter_v4/`（约 66 MB），替换 v3 即可。

---

## 一、v4 与 v3 的差别（先看这张表）

| 项 | v3 | v4 |
|---|---|---|
| 数据形态 | 单轮（1 问 1 答） | **多轮**（2–6 轮，含工具结果回灌） |
| 数据条数 | 440 条样本 | **549 段对话 / 1,029 轮** |
| 上下文 | 无 | 上一轮结果以 `检索结果：{json}` 注入 |
| system prompt | 单轮版 | **多轮版**（`V4_SYSTEM_PROMPT`） |
| max_len | 512 | **2048** |
| 能力 | 工具选择 / 对话 / 点评 | 以上全部 **+ 继承 / 指代 / 切换 / 纠错 / 澄清** |

**v4 已包含 v3 的全部单轮能力**（309 条单轮样本 + 240 段多轮），不要再把 v3 数据拼进来，会造成 300 多条重复。

---

## 二、数据格式（多轮 + 上下文记录）

```json
{"messages": [
  {"role": "system", "content": "<V4_SYSTEM_PROMPT>"},
  {"role": "user", "content": "找餐具套装"},
  {"role": "assistant", "content": "{\"action\":\"tool\",\"tool\":\"text_search\",\"arguments\":{\"query\":\"餐具套装\",\"category\":\"厨房用品\",\"top_k\":5},\"say\":\"我先帮你找找\"}"},
  {"role": "user", "content": "检索结果：{\"items\":[{\"item_id\":\"B07HJ4DPFT\",\"item_name\":\"...\",\"type\":\"餐具套装\",\"color\":\"白色\",\"material\":\"未识别\",\"similarity\":0.44}]}"},
  {"role": "assistant", "content": "{\"action\":\"reply\",\"text\":\"这几款以白色为主，餐具套装居多…\"}"},
  {"role": "user", "content": "换成白色"},
  {"role": "assistant", "content": "{\"action\":\"tool\",\"tool\":\"text_search\",\"arguments\":{\"query\":\"白色\",\"category\":\"厨房用品\",\"top_k\":8}}"}
]}
```

三条硬规则：

1. **工具结果一律用 `检索结果：` 开头**，作为 `user` 消息注入——这是“上下文记录”，模型只能引用其中的字段；
2. 角色严格交替：system → user → assistant → user → assistant …，**最后一条必须是 assistant**；
3. assistant 只输出协议 JSON（`action` 为 `tool` 或 `reply`），不带解释、不带 Markdown。

## 三、覆盖的 6 类场景

| 场景 | 段数 | 例子（第 1 轮 → 第 2 轮） |
|---|---:|---|
| 省略继承 | 70 | 「找餐具套装」→「换成白色」（类目沿用厨房用品） |
| 指代查详情 | 50 | 「看看第 4 个的详情」→ `get_item_detail(item_id=上一轮第4个)` |
| 话题切换 | 40 | 「改成厨房用品」（丢掉旧颜色） |
| 纠错 | 40 | 「不要这个，要低帮的」（保留类目） |
| 澄清后补信息 | 40 | 「都行」→ 反问 →「家居用品」→ 检索 |
| 单轮（保留 v3 能力） | 309 | 工具选择 / 对话 / 点评 / 图片检索 |

统计（生成时自动打印）：工具 569（text 470 / image 25 / list 12 / detail 62）、回复 460。

## 四、数据从哪来 / 怎么生成

```bash
python scripts/agent/build_v4_dialogues.py                 # 生成到 data/agent/sft_v4
python scripts/agent/build_v4_dialogues.py --dry-run       # 只统计不写盘
python scripts/agent/build_v4_dialogues.py --seed 7        # 换随机种子
```

脚本做的事：

1. 复用 v3 的单轮生成器（工具/对话/点评/澄清），**统一换成 v4 的 system prompt**；
2. 从 `data/index_data_finetuned/*/items.csv` 取真实商品字段（id/名称/细分类/颜色/材质）生成多轮；
3. 校验：角色交替、JSON 合法、工具在白名单、`say` ≤30 字、reply 无价格/销量断言、无重复对话；
4. 按 90/10 切分，写 `train.jsonl` / `valid.jsonl` / `manifest.json` / `preview.md`。

**产物**：549 段（494 训练 + 55 验证），训练集约 1.0 MB。

生成后必须人工抽查 `data/agent/sft_v4/preview.md` 的前 3 段：上下文是否接得上、点评是否只引用给定字段。

## 五、训练配置

| 项 | 值 |
|---|---|
| 基座 | `Qwen/Qwen3-4B-Instruct-2507`，4bit QLoRA |
| LoRA | r=16 / alpha=32 / dropout=0.05 |
| epoch | 2 |
| lr | 1e-4，cosine |
| batch | 1 + 梯度累积 8 |
| **max_len** | **2048**（v3 是 512，多轮更长；不够会截断历史） |
| 数据目录 | `data/agent/sft_v4` |
| 产物 | `dist/lora_adapter_v4/` |

复用 `scripts/agent/finetune/train_lora.py`，只改数据目录和 max_len。

> 显存提示：max_len 2048 + 4bit 4B 在 8 GB 卡上偏紧。若 OOM，先把 batch 保持 1、梯度累积加到 16，其次才降 max_len 到 1536。

## 六、训练后怎么检验

### 1. 单轮回归（不能退化）

```bash
python scripts/agent/eval_v3_dialogue.py \
  --model models/models/Qwen--Qwen3-4B-Instruct-2507/snapshots/master \
  --adapter dist/lora_adapter_v4
```

阈值同 v3：JSON ≥95%、action ≥90%、整体命中 ≥90%、回复无价格断言。

### 2. 多轮抽查（人工，10 段）

按下面脚本逐段跑，检查「第 2 轮有没有继承第 1 轮的条件」：

1. 找运动鞋 → 要白色的 → 还有别的吗
2. 找保温杯 → 换成黑色
3. 找双肩包 → 第二个什么材质
4. 找牛仔裤 → 不要这个，要直筒的
5. 随便看看 → 运动鞋 → 再便宜点的
6. 找手机壳 → 改成厨房用品
7. 看看第五个的详情
8. 你好 → 找运动鞋
9. 找白色运动鞋 → 还有吗
10. 找水杯 → 换个颜色

判定：第 2 轮是否**不需要用户重复类目**、是否没有串味（颜色串到别的类目）、是否引用了上一轮 item_id。

### 3. 端到端

起后端 → `/agent` 页连发 3 轮，看 `thinking` 是否体现“槽位/历史”，点评是否和卡片一致。

## 七、上线切换

1. 提交 `dist/lora_adapter_v4/`（`.gitignore` 已放行 `dist/lora_adapter*`）；
2. 后端**自动优先**加载 v4（优先级 v4 > v3 > v2），不用改配置；
3. 后端还需两处配合（代码侧，训练同学不用管）：
   - system prompt 换成 `V4_SYSTEM_PROMPT`；
   - 第二轮注入格式改成单条 `检索结果：{json}`，并按 `session_id` 保留历史轮次。
4. 重启 uvicorn，日志确认 `adapter=...lora_adapter_v4`。

**回滚**：删掉/改名 v4 目录即回到 v3，10 秒完成。

## 八、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 第 2 轮忘记类目 | 多轮样本太少或 max_len 截断 | 提高继承类占比，确认 max_len=2048 |
| 把上一轮颜色串到新类目 | 切换样本不足 | 增加「换类目」样本（现有 40 段） |
| 点评引用不存在的字段 | 注入的结果里没有该字段 | 检查生成器：只允许真实 CSV 字段 |
| 多轮后回复变短/敷衍 | 训练被单轮主导 | 多轮:单轮 ≈ 1:1，现为 240:309，可再补多轮 |
| OOM | max_len 2048 + batch 1 仍不够 | 梯度累积 16，或 max_len 降到 1536 |
