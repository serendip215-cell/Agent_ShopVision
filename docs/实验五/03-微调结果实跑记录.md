## 二、模型下载的坑（重要，换机器会遇到）

AutoDL 上 **HuggingFace 直连不通**（`curl` 返回 000），`hf-mirror.com` 可达但 `huggingface_hub 2.4.0` 对 `HF_ENDPOINT` 的处理变了，`AutoConfig.from_pretrained("Qwen/Qwen3-4B-Instruct-2507")` 仍然失败，报 `OSError: Can't load the configuration`；`hf_hub_download` 还报 `TypeError: process() takes no keyword arguments`。

**可行的解法：走 ModelScope 下载。**

```python
from modelscope import snapshot_download
p = snapshot_download('Qwen/Qwen3-4B-Instruct-2507', cache_dir='/root/models')
# -> /root/models/models/Qwen--Qwen3-4B-Instruct-2507/snapshots/master
```

下载约 8GB（3 个 safetensors 分片），实测 5–19 MB/s 波动，用时 **9 分 17 秒**。
拿到本地路径后，训练脚本用 `--model <本地路径>` 即可，完全不依赖 HF。

  --epochs 3 --batch-size 2 --grad-accum 8 --lr 1e-4 \

## 五、tool_call 为 0 的真实原因（不掩盖）

唯一那条验证样本（`tool_call_092`）的实际输出：

```json
// 模型输出
{"tool":"tool_search","arguments":{"query":"红色、黑色 带盖炒锅","category":"厨房用品","top_k":5}}
// 正确答案
{"tool":"text_search","arguments":{"query":"红色、黑色 带盖炒锅","category":"厨房用品","top_k":5}}
```

**`query`、`category`、`top_k` 三个参数全部正确**，只是工具名把 `text_search` 写成了 `tool_search`。

根因：
- 训练集里 tool_call 只有 **14 条**，验证集只有 **1 条**
- 工具名是「白名单硬约束」，评测里工具名错则整条判 0 分（这个口径是对的，不能放宽）
- 4B 模型在 14 条样本下没把专有名词记牢

**这不是评测口径问题，是真实的能力缺口。** 修法（任选其一，属后续工作）：
1. 补 tool_call 样本到 40–60 条重新微调（最有效）
2. 在 system prompt 里显式列出白名单工具名（成本最低，可立刻验证）
3. 5.3 的 `_parse_intent` 加一层工具名纠错（编辑距离匹配白名单）

**必须如实标注**：验证集 11 条、tool_call 仅 1 条，**该单项百分比不具统计意义**。任务书要求的「10 轮工具调用准确率 ≥90%」必须在 5.4 端到端联调用真实 10 轮对话测，不能用这 1 条充数。

## 七、复现步骤（任何 CUDA 机器）

```bash
# 1. 上传最小包（22KB）
scp -P <port> dist/exp5-5.2-upload.tar.gz root@<host>:~/
ssh -p <port> root@<host> 'tar -xzf exp5-5.2-upload.tar.gz'

# 2. 装依赖
pip install -r scripts/agent/finetune/requirements.txt

# 3. 下模型（走 ModelScope，别用 HF）
python -c "from modelscope import snapshot_download; print(snapshot_download('Qwen/Qwen3-4B-Instruct-2507', cache_dir='/root/models'))"

# 4. 训练
python scripts/agent/finetune/train_lora.py --model <模型路径> --output /root/runs/run1

# 5. 评测对比
python scripts/agent/finetune/eval_baseline_vs_lora.py --model <模型路径> --tag baseline
python scripts/agent/finetune/eval_baseline_vs_lora.py --model <模型路径> --adapter /root/runs/run1/final_adapter --tag lora
python scripts/agent/finetune/eval_baseline_vs_lora.py --compare <baseline.json> <lora.json>
```
