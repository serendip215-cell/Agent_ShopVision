# docs 目录导航

本目录按「性质」分四类，正在工作的报告源与脚本留在原位不动。**先看这张表再进去翻。**

```text
docs/
├── 课程材料/       课程发的原始材料，只读不改（开课 PDF、任务书、报告模板 .doc）
├── 方案与指南/     各阶段的技术方案与使用指南，写于对应步骤之前
├── 流程与交接/     每个实验的流程与分工、训练机交接说明
├── 交付材料/       已提交的实验交付物（报告 PDF、截图、下载链接、训练凭证）
├── typ/           实验报告 Typst 源：.typ、refs.bib、figures/（CeTZ 源+SVG）、figs/（数据图）
├── scripts/       报告编译脚本 build_typ.sh/.cmd、gen_figures*.py
├── finetune/      实验二微调的完整记录（数据转换→训练→结果→补丁→对照组）与入库凭证
├── build/         编译产物 PDF（不入 git）
└── typst/         Typst 编译器，首次运行自动下载（不入 git）
```

## 实验记录放哪

| 实验 | 记录写在 |
|---|---|
| 实验一 | `docs/typ/实验一.typ`；数据集说明在 `data/raw_data/README.md` |
| 实验二 | `docs/finetune/01`–`05`；入库凭证 `docs/finetune/runs/<RUN_ID>/`；检索评测在 `evaluation/retrieval/` |
| 实验三 | `docs/optimize/README.md`（**做了什么 + 结果存放位置总表**）；方法口径 `00`、代码清单 `01`、主任务 `02`；凭证 `docs/optimize/runs/<RUN_ID>/` |

## 新增文档放哪

- 课程发的原件 → `课程材料/`；写于实施之前的方案 → `方案与指南/`；
- 某个实验的流程、分工、交接说明 → `流程与交接/`（文件以实验名开头）；
- 该实验的实际记录与凭证 → 对应的 `docs/<主题>/`（如 `finetune/`、`optimize/`），**记录与方案不要混在一个目录**；
- 报告源一律放 `docs/typ/`（编译脚本按 `docs/typ/*.typ` 扫描）。

## 报告编译

见根 README「实验报告编译」一节，或用：

```powershell
docs\scripts\build_typ.cmd 实验三      # 编译 docs\typ\实验三.typ，输出到 docs\build\
```
