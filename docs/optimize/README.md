## 结论（一句话）

**3.1.4 三项指标全部达标**：TensorRT 相对 PyTorch 推理 **延迟 −57.7%（batch1）/ −52.7%（batch32）**、

## 已冻结的 3.1.1 结论（留档）

体积：FP32 718.29 MB → FP16 359.21 MB（−50.0%）→ INT8 313.88 MB（−56.3%）。
精度（934 条 test，R@1）：FP32 58.57 / FP16 **58.46** / INT8 6.64 / per-channel 25.05 / 只文本塔 8.89 / 只图像塔 45.40。

**冻结原因**：任务书的量化指标要求精度损失 ≤2%，而裸动态量化最好也只到 −13.06pp；继续投入需 ONNX 静态量化 + 校准 + 量化后微调，属于高不确定投入。**同等时间投入 3.1.4 的达标概率明显更高**（其精度一致性指标 FP16 已满足）。

> 注：任务书的"体积减少 75%"是"如 FP32→INT8"的**举例**，不是独立验收项；硬指标是精度损失 ≤2%。
