# 亚马逊数据中文化处理方案

## 1. 目的

将 `Amazon_data` 中的商品文本字段统一整理为中文，并生成与当前 `MUGE_data` 相同结构的 Amazon 中文翻译暂存数据，供后续整理和检查使用。

本方案只规定数据处理后的格式和规则，不改变原始数据的组织方式。

## 2. 处理原则

1. `data/raw_data/Amazon_data/` 作为原始数据，只读保存，不直接覆盖。
2. 翻译后的 Amazon 数据先单独放入 `Amazon_data_translated` 暂存目录，结构与 MUGE 数据集一致。
3. 处理后的商品文本统一使用中文。
4. 处理后的 `products.csv` 不增加英文原文列。
5. 图片文件不因为文字翻译而重新生成或修改。
6. 无法可靠翻译或判断的内容保持为空，不根据图片主观补写。
7. 图片路径、尺寸、文件状态和哈希值等技术字段保持可追溯。

## 3. 输入和输出目录

### 3.1 原始输入

```text
data/raw_data/Amazon_data/
├── products.csv
├── images/
├── image_quality_report.csv
└── README.md（如有）
```

原始 `products.csv` 和图片文件不覆盖、不改名。Amazon 原始标题和属性只作为翻译输入，不直接进入处理后的训练表。

### 3.2 翻译暂存输出

```text
data/raw_data/Amazon_data_translated/
├── products.csv
├── images/
├── image_quality_report.csv
└── README.md
```

翻译暂存目录使用与 `MUGE_data` 相同的三个核心数据文件：商品表、图片目录和图片质量报告。`README.md` 用于记录数据来源、翻译规则和处理统计。这个目录仍处于整理阶段，不能直接视为正式训练数据。

### 3.3 正式处理输出

完成字段整理、路径检查、图片对应检查和质量审核后，再按 `product_type` 生成到：

```text
data/processed_data/<product_type>/
├── products.csv
├── images/
├── image_quality_report.csv
└── field_check_report.json
```

正式处理数据按商品类别组织，不再按 Amazon、MUGE 等数据来源组织。

## 4. `products.csv` 字段规范

翻译暂存和正式处理后的 `products.csv` 统一使用 11 个字段；正式处理数据按 `product_type` 分目录保存：

```text
item_id
product_type
item_name
description
brand
color
material
local_image_path
image_status
image_height
image_width
```

### 4.1 需要翻译或中文化的字段

| 字段 | 中文化规则 |
|---|---|
| `product_type` | 使用较宽的中文商品大类，例如 `包`、`鞋`、`水杯`；不能可靠判断时留空，不强行归类。 |
| `item_name` | 将商品标题翻译为中文，保留商品的主要类别、品牌、颜色和关键特征，不添加原文中没有的功能或宣传内容。 |
| `description` | 根据标题、原始属性和人工确认结果整理简短中文描述；不能确认的细节不写入。 |
| `brand` | 使用稳定的中文品牌名；品牌专名没有可靠中文译名时不进行臆造或直译。 |
| `color` | 翻译为中文颜色名称，并统一同义表达，例如 `blue`、`navy blue` 归一为约定的中文颜色词。 |
| `material` | 翻译为中文材质名称；多个材质按统一分隔规则保存。 |

### 4.2 不翻译的字段

以下字段是标识、路径或技术信息，应保持原值：

```text
item_id
local_image_path
image_status
image_height
image_width
```

### 4.3 缺失值规则

- 单值字段缺失使用空字符串；
- 不使用 `unknown`、`N/A`、`null`、`NaN` 混合表示缺失；
- 不从商品图片推测品牌、颜色或材质；
- 翻译失败的字段保持为空，并在 `README.md` 的统计中记录数量；
- `description` 用于保存经过确认的中文商品描述；不能确认的内容保持为空；
- 不新增 `price`、`tags` 等当前统一格式没有的字段。

## 5. 类别处理规则

“与 MUGE 格式一致”首先指字段、路径和文件结构一致，不表示 Amazon 的原始类别必须全部强行映射为 MUGE 的三类类别。

类别处理分两步：

1. 将 Amazon 原始类别翻译为中文，写入 `product_type`；
2. 如果后续训练只使用 MUGE 的目标类别，再根据明确的类别映射筛选训练数据。

无法可靠映射到目标类别的商品不删除原始记录，也不伪造类别；它们可以保留在中文化数据集中，但不进入限定类别的训练子集。

## 6. 图片和路径处理

1. 图片内容不因翻译而改变；
2. 翻译暂存阶段的图片放入 `data/raw_data/Amazon_data_translated/images/`；正式处理阶段再放入对应的 `data/processed_data/<product_type>/images/`；
3. `local_image_path` 使用仓库根目录相对路径；
4. 路径统一使用 `/`，不使用 Windows 反斜杠；
5. `products.csv` 中的每个图片路径都必须能定位到实际文件；
6. 图片尺寸沿用实际检查结果，写入 `image_height` 和 `image_width`；
7. 完全相同的图片只保存一份，但保留所有商品记录与该图片的关联。

## 7. `image_quality_report.csv` 规范

处理后的报告字段与 MUGE 保持一致：

```text
dataset_id
source_product_id
image_path
decode_ok
actual_height
actual_width
declared_height
declared_width
format
file_size_bytes
sha256
quality_status
quality_reason
```

报告主要检查图片文件本身，不翻译图片内容。报告中的 `image_path` 必须指向当前阶段目录中的图片；翻译暂存阶段指向 `Amazon_data_translated/images/`，正式处理阶段指向 `processed_data/<product_type>/images/`。`quality_status` 继续使用 `pass`、`review`、`failed` 等统一值。

图片能打开只代表文件完整，不代表图片一定是清晰的商品主图，也不代表图片和商品文字一定匹配。内容审核属于后续训练数据审核阶段。

## 8. 输出示例

处理后的 `products.csv` 示例：

```csv
item_id,product_type,item_name,description,brand,color,material,local_image_path,image_status,image_height,image_width
B01MTEI8M6,鞋,女士法式花卉刺绣休闲便鞋,女士低帮休闲鞋，鞋面材质为皮革，适合日常穿着。,The Fix,棕褐色,皮革,data/raw_data/Amazon_data_translated/images/714CmIfKIYL.jpg,ok,868,1779
```

字段顺序、图片路径写法和 MUGE 数据集保持一致；商品标题、类别、颜色和材质使用中文。

## 9. 处理后检查

中文化数据生成后，需要确认：

- `products.csv` 的字段顺序与统一规范一致；
- 正式处理数据位于 `data/processed_data/<product_type>/`，不按 Amazon 或 MUGE 来源分目录；
- 没有新增英文原文列；
- 商品标题、类别、颜色和材质字段使用中文或明确的品牌专名；
- `item_id`、图片路径和尺寸没有被翻译或改变；
- 每条商品记录的图片路径都存在；
- 图片质量报告中的图片数量与图片目录可核对；
- 不存在绝对路径；
- 原始 Amazon 数据仍然可以单独追溯；
- 翻译为空的字段数量和原因已记录在输出目录的 `README.md` 中。

## 10. 与后续中文检索的关系

完成正式整理后，Amazon 数据和 MUGE 数据可以使用同一套中文文本检索流程：

```text
Amazon 中文商品标题 ─┐
                     ├─ 中文文本编码器 ──> 中文文本向量
MUGE 中文商品标题 ───┘
```

图片继续使用各自的本地路径和图片向量。后续合并检索时，如果需要区分数据来源，再额外记录一个最小的 `source` 标识；不需要把英文原始标题加入训练字段。

## 11. 验收标准

只有同时满足以下条件，中文化 Amazon 数据才可进入中文图文检索训练：

1. 输出目录结构与 MUGE 一致；
2. `products.csv` 表头与 MUGE 一致；
3. 处理后的文本字段已经完成中文化；
4. 商品 ID、图片路径和图片文件一一对应；
5. 图片质量报告已重新指向处理后图片；
6. 原始数据未被覆盖；
7. 缺失和翻译失败字段已统计；
8. 未可靠映射的类别没有被强行标注。
