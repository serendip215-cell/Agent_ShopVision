# deepseekv4_1_flash_pilot_20261018：AI 复核检索试点评测

## 本轮结果

- 查询总数：生成 135 条，AI 复核后纳入 132 条、排除 3 条。
- 最终 qrels：1325 条判断；最终排名：1320 行（有效查询 × Top-10）。
- 评价口径：AI 按视觉商品相似度及查询明确提出的条件评审候选；文字查询将源商品作为确定性相关锚点。全程使用这一套 qrels。
- 数据用途：作为后续融合权重调优的试点验证集。查询和候选标签由 AI 生成/复核，文字查询另保留源商品锚点；结果不是独立最终测试集或人工真值。

| 查询模式 | 查询数 | Precision@10 | nDCG@10 | MRR@10 |
|---|---:|---:|---:|---:|
| 文字 | 44 | 0.300 | 0.868 | 0.865 |
| 图片 | 45 | 0.391 | 0.874 | 0.804 |
| 图文 | 43 | 0.263 | 0.862 | 0.651 |

## 结果解释

图片查询的 Precision@10 为 0.391，高于文字查询的 0.300 和图文查询的 0.263。文字查询的 MRR@10 为 0.865，图文查询为 0.651。本轮尚未显示图文融合优于单独查询。后续可固定本目录中的 inputs/queries.csv、inputs/qrels.csv 与索引，比较不同融合权重。

3 条查询因明显错字或图文条件冲突被 AI 复核排除，原因见 query_audit.csv；所有 135 条原始查询仍保存在 inputs/queries_generated.csv。AI 复核修订了 2 条候选相关度，逐项依据见 ai_review.csv。

图像/图文判断主要覆盖已返回的 Top-10 候选，因此 Recall 受候选池截断影响，不代表完整召回率。查询由索引商品字段生成，也可能带来源商品偏差；本结果仅用于初步调参和错误分析。

## 统一调优输入

后续调优只使用：
- inputs/queries.csv：AI 复核通过的查询；
- inputs/qrels.csv：唯一最终相关性标签（AI 候选判断与文字查询源商品锚点）；
- ranked_results.csv、query_metrics.csv、summary.json：本轮固定检索结果和指标。

不同权重实验必须使用相同查询、qrels、索引、Chinese-CLIP 权重、Top-K 和候选数，并使用新的 run-id 保存结果。最终测试应另建来源商品不重叠的留出集。

## 文件说明

| 文件/目录 | 内容与作用 | 后续调优、分析或写作时怎么用 |
|---|---|
| `inputs/queries.csv` | 通过 AI 有效性复核并实际计入指标的文字、图片和图文查询。 | **调优必需**：每组权重实验都使用同一份查询；论文描述评测查询。 |
| `inputs/qrels.csv` | 唯一正式的 0–3 级相关性标签，包含 AI 候选判断及文字查询的源商品锚点。 | **调优必需**：与 `queries.csv` 配套固定；论文计算指标的相关性依据。 |
| `inputs/queries_generated.csv` | 全部 135 条生成查询，保留被排除查询及其原始输入字段。 | 追踪 AI 筛选前后的变化；不直接进入指标计算。 |
| `inputs/query_manifest.csv` | 查询、类别、查询模式、源商品和生成来源的映射。 | 检查来源商品泄漏，后续构建不重叠的独立测试集。 |
| `inputs/retrieval_config.json` | 本轮检索配置快照，包括检索通道和融合参数。 | 复现本轮设置、确认调优对比只改变目标参数。 |
| `ai_review.csv` | 逐 query-item 的相关度、理由、置信度和查询状态，并区分 AI 评分与源商品锚点。 | 审计 AI 判断、分析错标；**机器评测以 `qrels.csv` 为准**。 |
| `query_audit.csv` | 每条查询的 AI 有效性判断、纳入/排除状态和理由。 | 解释排除的 3 条查询，分析查询构造质量和数据偏差。 |
| `ranked_results.csv` | 132 条有效查询各自 Top-10 商品、排名、分项相似度和融合分数。 | **调优诊断核心材料**：定位错误结果、分析图片/文本通道及权重影响；可摘取论文案例。 |
| `query_metrics.csv` | 每条有效查询的 Precision、Recall、nDCG、MRR、首个相关结果排名等指标。 | **调优对比核心材料**：观察哪些查询提升或退化；可重新汇总和绘图。 |
| `summary.json` | 分文字、图片、图文模式及类别汇总的机器可读指标、口径和用途。 | 脚本读取、不同实验结果自动比较；论文表格的数据来源之一。 |
| `run_metadata.json` | Chinese-CLIP、索引类别、权重、Top-K、输入快照相对路径等实验设置。 | 判断不同 run 是否可比并记录复现条件；可用于论文实验设置。 |
| `api_usage.json` | AI 模型名、服务地址、当前进程调用次数和 token 统计，不含 API Key。 | 估算 AI 评审成本；本轮从检查点恢复过，不能把该文件的单次统计当作完整总调用量。 |
| `contact_sheets/` | 90 张图片/图文查询与 Top-10 候选的联系表，总计约 8 MB。 | 复查视觉判定、挑选论文定性示例；不参与指标计算。 |
| `metrics_by_mode.png` | 文字、图片和图文查询的指标对比图。 | 论文结果图；也可从 `query_metrics.csv` 重新绘制。 |
| `first_relevant_rank.png` | 首个相关商品的排名分布图。 | 说明用户大致需要浏览到第几位才会看到相关商品；可重绘。 |
| `sample_topk_scores.png` | 示例查询的 Top-K 分项分数和融合分数图。 | 解释排序结果及权重作用；可从 `ranked_results.csv` 重绘。 |
| `测试结果说明.md` | 本轮结论、指标、限制、调优入口和文件说明。 | 人阅读的入口；不作为程序输入。 |
